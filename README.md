# 翻转灯谜求解器

一个运行在浏览器里的「翻转灯谜」（Lights Out）求解器。给出任意矩形棋盘，它能判断能否全部熄灭（或点亮）；能的话，给出**点击总次数最少**的方案。

所有计算都在本地浏览器里完成。

## 这是什么

翻转灯谜的规则：点击一格，它自己和上下左右四邻（共五格）一起翻转。目标是让整盘灯全部熄灭。

这个网页求解器做的事：

1. 设置一个任意大小的棋盘（行、列各最多 64），手动摆灯或用随机生成。
2. 点「求解」，算出最少需要点击哪些格子。
3. 照着棋盘上的标记点下去，直到完成。

## 算法简介

把每盏灯的状态看作二进制数（0 灭、1 亮），点击的翻转规则就是模 2 加法。于是问题变成一个 GF(2) 上的线性方程组：

- 未知数是「每个格子是否点击」，方程是「每个格子最终是否为灭」。
- 解这个线性方程组，得到**一个特解**和**零空间的一组基**。
- 零空间的维数记作 `d`，它决定解的个数 `2^d`：`d = 0` 时解唯一；`d` 越大，解越多，需要枚举的也越多。
- 在 `2^d` 个有效解上用**格雷码**依次枚举，每次只翻一位，就能找到点击次数最少的那个；枚举完成，最优性即被证明。

因此「最少点击」是精确的数学结果，不是启发式猜测。当 `d` 太大、枚举在时限内跑不完时，它会返回当前找到的最好解，并**明确标注「最优性未证明」**，而不是假装算完了。

真正的计算瓶颈不是行列数，而是零空间维数 `d`：`d` 小（绝大多数尺寸）瞬间精确解出，`d` 超过 20 左右才需要枚举。
